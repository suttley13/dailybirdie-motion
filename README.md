# Daily Birdie motion maps

Generated data, not source. Each file says where one published course illustration's holes and
surfaces are, so the app can draw its miniature golfer on top. A workflow in the private Daily
Birdie repository writes everything here, so please don't edit it by hand.

- `v1/<artwork sha256>.json` is one map, in format version 1.
- `status.json` records what happened to each artwork. An artwork with no map keeps its still art.

Nothing here can affect the course content, the game or released apps.
